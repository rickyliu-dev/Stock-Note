# Stock Note 股票記帳 APP

個人開發的股票記帳應用程式,使用 Jetpack Compose 打造,協助記錄股票交易並查詢股價資訊。

## 功能

- 手動記錄股票交易(買入/賣出)
- 串接 Yahoo Finance API,提供股票/ETF 搜尋與非即時股價查詢,並處理台股代碼格式清理
- 使用 Room 進行本地資料儲存

## 技術棧

- **語言**:Kotlin
- **UI**:Jetpack Compose
- **架構**:MVVM
- **本地資料庫**:Room
- **網路請求**:OkHttp
- **非同步處理**:Coroutines

## 開發方式

此專案開發過程中,運用多種 AI 開發工具(如 Claude Code 等)輔助程式撰寫、除錯與架構規劃,並持續驗證、調整程式邏輯,加速開發流程。

## 開發動機

單純想開發一款 APP 作為個人練習,剛好自己有股票記帳的需求,便以此為主題發想開發,同時也提供給家人使用,並藉此深化對 Jetpack Compose 與 MVVM 架構的實作經驗。
